# eCommerceX frontend

Next.js storefront and admin console. Setup, stack, and Docker notes live in the [root README](../README.md).

```bash
cp .env.example .env.local   # NEXT_PUBLIC_API_URL=http://localhost:4000/api/v1
yarn install
yarn dev                     # http://localhost:3000
```

Store: `/` · Admin: `/admin`
